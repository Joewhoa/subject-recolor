# 可以直接复制给 Agent 的话

## 1. 第一次使用（推荐整段复制）

```text
请使用“新方案交接落地/一次性换色脚本/一次性换色.py”这个脚本，替我这个完全不懂 Python 的用户完成一次图片换色。

先读该目录下的 README_先看.md，然后按顺序：
1. 运行 `python 一次性换色.py --check` 检查环境，不调用 API；
2. 用我的原图和色卡显式跑 `--profile B --dry-run`，把取色得到的 RGB/HEX、颜色描述、主体、提示词和“只会有 1 次调用”用大白话告诉我，这一步不收费；
3. 等我确认后，再用 `--profile B --yes` 做唯一一次付费调用，并在调用前明确告诉我只有 1 次、要花钱；A 只能在我明确指定某一项复检时单独运行；
4. 成功后把 PNG、JPG、结果 JSON 和审阅页路径给我，并解释结果。

规则：用 system curl（该部署的验证适配器）而不是 httpx；默认 B 增强方案，A 只在用户明确指定的个别复检中单独运行，绝不 A+B 双跑；API Key 从环境读取，不得进入 Git、持久配置、应用日志、curl argv、终端/聊天或输出产物，仅可在每次调用期间进入权限受限的短期临时 curl header 文件并在调用后尽力删除；权限限制或清理失败按本机安全卫生问题停止并检查，不承诺绝对无本地残留；真实网关不得写死，必须从 `SUB2API_BASE_URL` 或 `--base-url` 注入；超时/传输中断/2xx 缺图以及 503 属于 uncertain，立即停止且禁止自动重试；只有 HTTP 429 或确认连接未建立（curl exit 5/6/7 且 HTTP 0）才最多补试一次；curl 无法启动是本地 fatal，不自动重试；request_id 只用于追踪，不是幂等键；400/401/403 直接停止。同一身份只要已有任一结果产物或 attempt sidecar 就拒绝重跑；Agent必须先让用户审阅现有文件，只有用户明确授权后才可改用全新的 `--out`。用户不懂代码，每一步都要说清是否花钱。
```

## 2. 处理具体一张图（把路径换成真实的）

```text
请处理这张原图：<原图路径>，目标色来自色卡：<色卡路径>（或直接用颜色 <#RRGGBB>）。主体是<户外窗帘>。默认显式使用 `--profile B`：先配合 `--dry-run` 给我看取色和提示词，我确认后再配合 `--yes` 做唯一一次付费调用。只有我明确说“对这一项用 A 复检”时才改为 `--profile A`，不得 A+B 双跑。遇到 uncertain 不要重试，先对账。
```

## 3. 只检查、不调用 API

```text
请只做完全离线检查，不要调用付费 API。运行 --check 和 --dry-run，检查原图/色卡能否读取、中心 200×200 取色的 RGB/HEX、生成的提示词、输出目录和预计调用数（应该是 1）。用小白能听懂的话汇报。
```

## 4. 出现 uncertain

```text
任务出现 uncertain。请立即停止所有新调用，读结果 JSON 或终端输出，整理 request_id、提交时间、错误信息和可能是否扣费。不要重试，不要换脚本绕过。给我一份可用于对账的简明报告，等我确认未扣费后再决定。
```

# 一次性换色脚本｜先看这里

这是给“**用户完全不懂 Python、由 Agent 代劳**”的本地落地版。和批量工具走同一条已验证路线：**system curl（该部署的验证适配器）发请求 + B 增强方案 + 中心取色**，但把整批流程收敛成最简单的**一次请求**。B 是默认方案，A 是显式可选的个别复检方案，绝不默认 A+B 双跑。

- 一张原图 + 一个颜色 = 一次付费图片编辑请求；
- 没有批量笛卡尔积、没有 checkpoint、没有 CSV、没有并发；
- API Key 从进程环境读取，不进入 Git、持久配置、应用日志、curl 命令行参数（argv）、终端/聊天或输出产物；仅在每次调用期间写入权限受限的短期临时 curl header 文件，并在调用后尽力删除。权限限制或清理失败属于需要 Agent 检查的本机安全卫生问题，不承诺不可能留下任何本地残留。

## 目录

```text
一次性换色脚本/
├── 一次性换色.py          # 唯一脚本，Agent 直接运行
├── requirements.txt       # 只有一个依赖：Pillow
├── README_先看.md         # 本文件
└── 复制给Agent的话.md     # 用户可以直接复制粘贴给 Agent 的说明
```

## 用户只需要做什么

1. 准备一张**原图**，例如 `客厅窗帘.jpg`；
2. 准备一个**颜色来源**，二选一：
   - 一张**色卡图片**，例如 `色卡_深蓝.png`；
   - 或者直接告诉 Agent 一个十六进制颜色，例如 `#2F6B63`；
3. 把下面这段话复制给 Agent（见 `复制给Agent的话.md`）。

其余全部交给 Agent。用户不需要安装 Python、不需要碰命令行。

## 三个不收费的步骤

Agent 会先做这些，**全部不收费、不调用 API**：

```bash
# 1. 环境自检
python 一次性换色.py --check

# 2. 预览：默认 B；看取色结果、提示词和“只会有 1 次调用”
python 一次性换色.py 原图.jpg --card 色卡.png --profile B --dry-run
```

用户确认颜色和目标没问题后，Agent 才做唯一一次付费调用。

## 付费调用（Agent 代劳）

```bash
# 默认生产调用：B
python 一次性换色.py 原图.jpg --card 色卡.png --subject 户外窗帘 --profile B --yes

# 只有用户明确指定某一项复检时才用 A；不得与 B 自动双跑
python 一次性换色.py 原图.jpg --card 色卡.png --subject 户外窗帘 --profile A --yes
```

- 输出默认写到 `结果/` 目录，文件名带 profile，A/B 不会互相覆盖：
  - `<原图名>__<色值>__B_结果.png` 或 `__A_结果.png`（模型原始 PNG）
  - `<原图名>__<色值>__B_结果.jpg` 或 `__A_结果.jpg`（网页预览）
  - `<原图名>__<色值>__B_结果.json` 或 `__A_结果.json`（request_id、用量、颜色、提示词）
  - `<原图名>__<色值>__B_审阅.html` 或 `__A_审阅.html`（原图 | 目标色 | 结果 三联对比）
  - `<原图名>__<色值>__B_attempt.json` 或 `__A_attempt.json`（每次提交状态和 request_id）

同一身份只要已有任一结果产物或 attempt sidecar，脚本就拒绝重跑，不能通过删除或忽略其中某个文件来绕过。Agent必须先让用户审阅现有产物和尝试记录；只有用户明确授权再次付费后，才可使用一个全新的`--out`路径发起新尝试。

## 环境变量（由 Agent 配置，用户不管）

- `SUB2API_API_KEY`：图片编辑接口的 Key（必需）；
- `SUB2API_BASE_URL`：网关地址（必需，不内置真实部署地址）；
- `RECOLOR_MODEL`：模型，默认 `gpt-image-2`。

## 安全规则（与正式工具一致）

- 超时 / 传输中断 / 2xx 缺图：`uncertain`，**立即停止、绝不自动重试**；
- HTTP 503：默认按 `uncertain` 处理，**不自动重试**；
- 只有 HTTP 429 或已确认连接未建立（curl exit 5/6/7 且 HTTP 0）可最多**补试一次**，间隔 30 秒，仍失败就停止；
- curl 进程无法启动属于本地 `fatal/rejected`，请求未提交，**不自动重试**；
- 400 / 401 / 403 / 404 / 413 / 422：`rejected`，停止；
- 每个 request ID 只用于链路追踪，不是幂等键，换新 ID 不能防止重复计费；
- 成功：保留模型原始 PNG 字节，JPG 由 PNG 派生（quality 85、progressive）。

## 与批量工具的关系

- 批量工具 `正式工具_batch_recolor_tool/` 是**默认生产入口**，用于一次处理很多图×很多色卡、且要断点续跑的正式场景；
- 本脚本是**显式可选的快速试一张**方案，用于**快速试一张**，或用户只有一个图一个颜色时的最简落地；
- 两者都遵循同一条规则：B 默认、A 显式可选、503 默认 uncertain、只有 429/连接未建立才有限补试。

# 可以直接复制给Agent的话

## 1. 新Agent第一次接手（推荐）

```text
请接手“新方案交接落地”中的主体换色项目（默认示例主体为户外窗帘，可换成任意主体）。用户完全不懂Python，请你作为代操作员，不要只丢命令让我自己猜。

先阅读：
1. 00_README_先看这里.md
2. 文档/02_新Agent完整操作手册.md
3. 文档/04_故障诊断与费用安全.md
4. 文档/05_技术方案与验证结论.md

只使用“正式工具_batch_recolor_tool”作为默认生产入口（一次性换色脚本只用于单图单色的快速试一张）。正式方案是Python管理任务＋system curl（该部署的验证适配器）发送API；固定单线程；默认B；A只能由用户明确指定到个别复检任务，绝不A+B双跑。不要恢复httpx，不要擅自并发，不要上传色卡或mask。API Key从环境读取，不得进入Git、持久配置、应用日志、curl argv、终端/聊天或输出产物；仅在每次调用期间进入权限受限的短期临时curl header文件并在调用后尽力删除。权限限制或清理失败是需要Agent检查的本机安全卫生问题，不要承诺绝对无本地残留。私有网关不得写死在代码/文档中，只能在运行时注入。request ID只用于追踪，不是幂等键。

请先检查目录和环境，运行完全离线的check_environment.py及离线测试，再对我指定的日期目录做--dry-run和--prepare-only。这些步骤不收费。把原图数、色卡数、笛卡尔积、取色RGB/HEX、预计新增调用、压缩前后尺寸用小白能懂的话告诉我。

付费阶段先只用--limit 1测试一个B任务；执行前明确告诉我最多会调用几次并取得确认。成功后检查PNG/JPG/checkpoint/transport和审阅页，让我看首张后再问是否全量。遇到uncertain立即停止且禁止盲目重试；503默认按uncertain停止。只有HTTP 429或确认连接未建立（curl exit 5/6/7且HTTP 0）才允许最多一次安全补试；curl无法启动是本地fatal，不重试。
```


## 6. 出现uncertain

```text
任务出现uncertain。请立即停止所有新调用，读取checkpoint和events，整理task ID、request ID、提交时间、错误、可能调用费用和是否有本地输出。不要使用--retry-uncertain，也不要换脚本绕过。先给我一份可用于对账/反馈的简明报告，等我明确确认未扣费后再决定。
```

## 7. 出现空体503

```text
任务出现HTTP 503空响应。请确认正式版使用system curl（该部署的验证适配器）而不是httpx，读取request ID和耗时。503默认按uncertain处理：立即停止、不自动补试，其余任务保持pending；整理request ID、耗时和响应预览，给我一段可直接反馈给API拥有者的说明，等我确认未扣费后再决定是否继续。
```
